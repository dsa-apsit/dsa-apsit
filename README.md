# DSA APSIT

> Data Structures & Algorithms Club · APSIT

A student-driven community at **A. P. Shah Institute of Technology** focused on learning, building, and exploring **Data Structures, Algorithms, Competitive Programming, and Software Development**.

### What we do

- 🧠 DSA & Competitive Programming
- 💻 Coding workshops and hands-on sessions
- 🏆 Hackathons, contests & coding challenges
- 🚀 Technical projects and collaborations
- 🤝 Peer learning and developer community

### Our Work

This organization contains projects, resources, websites, and tools built by the **DSA APSIT Committee**.
